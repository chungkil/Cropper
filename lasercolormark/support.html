자주 묻는 질문

계산한 대로 마킹했는데 색이 다릅니다

정상입니다. 이 앱은 색을 예측하지 않습니다. 같은 플루언스라도 표면 조도, 유막, 소재 로트, 주변 온도에 따라 산화막 성장 속도가 달라집니다. 앱이 제공하는 것은 탐색 범위이며, 색은 테스트 매트릭스로 확정하는 것을 전제로 설계되어 있습니다.

펄스폭을 바꿀 수 없습니다

발진기 유형이 Q-switched로 설정된 경우입니다. Q-switched에서 펄스폭은 입력값이 아니라 주파수에서 파생되는 값이므로 컨트롤이 표시되지 않습니다. 유형이 확실하지 않다면 설정 > 프로파일에서 판별 마법사를 실행하세요.

컬러 팔레트가 비활성입니다

Q-switched 발진기에서는 컬러 마킹이 물리적으로 불가능하므로 금색·자주·청색·청록이 비활성화됩니다. 흑색·회색·백색·깊은 각인은 동일하게 사용할 수 있습니다.

레시피가 validated로 승격되지 않습니다

승격 조건은 서로 다른 소재 로트에서 2회 이상 재현입니다. 같은 로트에서 여러 번 성공해도 승격되지 않습니다. 로트 편차가 색상 재현의 가장 큰 변수이기 때문입니다.

발진기 유형을 바꾸니 레시피가 무효화되었습니다

의도된 동작입니다. 유형이 바뀌면 파라미터의 물리적 의미 자체가 달라지므로, 기존 값을 조용히 재해석하는 대신 무효화하고 보존합니다. 미확인(unknown)에서 유형을 확정하는 경우에만 레시피가 승계됩니다.

촬영한 색상 값이 실제와 다릅니다

캡처 기능은 18% 그레이 패치를 함께 촬영해 화이트밸런스를 보정합니다. 참조 카드 없이 촬영하거나, 그레이 패치가 너무 어둡거나 포화된 경우 측정이 거부됩니다. 측정값은 참고용이며, 색상 판정의 기준은 실물 견본판입니다.

Pro 를 샀는데 다른 기기에서 잠겨 있습니다

같은 Apple 계정으로 로그인한 뒤 설정 > 구매 > 구매 복원을 실행하세요. 비소모성 상품이므로 추가 결제 없이 복원됩니다.

무료로는 어디까지 쓸 수 있나요

계산 엔진 전체(F · OL_x · OL_y · N · CDE), 스팟 배열·단면·파라미터 스윕 뷰, 권장값 자동 탐색은 제한 없이 무료입니다. 여기에 장비 프로파일 1개와 테스트 매트릭스 1개가 포함되어, 매트릭스 생성 → EzCad 내보내기 → 셀 촬영 기록 → 레시피 저장까지 한 번은 끝까지 돌려볼 수 있습니다. 두 번째 매트릭스나 프로파일을 만들 때 Pro 해제($14.99, 1회 결제) 안내가 나타납니다.

전부 기기 안에만 저장됩니다. 계정도 서버도 없습니다. 자세한 내용은 개인정보 처리방침을 참고하세요.

Frequently asked questions

I marked exactly what it computed, but the color is different

That is expected. This app does not predict color. At the same fluence, oxide growth still varies with surface roughness, oil film, material lot and ambient temperature. What the app gives you is a search range; the color itself is meant to be settled with a test matrix.

I cannot change the pulse width

Your source type is set to Q-switched. There, pulse width is derived from frequency rather than entered, so the control is hidden. If you are unsure of the type, run the determination wizard from Settings > Profile.

The color palette is disabled

Color marking is physically impossible on a Q-switched source, so gold, purple, blue and cyan are disabled. Black, gray, white and deep engraving remain available.

My recipe will not promote to validated

Promotion requires reproduction across two different material lots. Repeated success within a single lot does not qualify, because lot variation is the largest source of color irreproducibility.

Changing the source type invalidated my recipes

That is intentional. When the type changes, the physical meaning of the parameters changes with it, so existing values are invalidated and preserved rather than silently reinterpreted. Recipes are carried over only when you are confirming a previously unknown type.

The captured color values do not match what I see

Capture corrects white balance using an 18% gray patch photographed alongside the sample. Without the reference card — or if the patch is too dark or saturated — the measurement is rejected. Values are for reference; a physical sample plate remains the authority on color judgment.

I bought Pro but it is locked on another device

Sign in with the same Apple Account, then use Settings > Purchase > Restore Purchases. It is a non-consumable, so it restores at no additional charge.

How far can I get on the free tier

The full calculation engine (F · OL_x · OL_y · N · CDE), the spot array, cross-section and parameter sweep views, and the automatic recommended-value search are free with no restrictions. The free tier also includes one machine profile and one test matrix, which is enough to run the whole loop once — generate a matrix, export to EzCad, photograph the cells and save a recipe. The Pro unlock ($14.99, one-time) is offered when you create a second matrix or profile.

Where is my data stored

Entirely on your device. There is no account and no server. See the privacy policy for details.

Safety notice
