시작하기Getting started

처음 열면 무엇을 고르나요?What do I choose on first launch?

주로 쓰는 언어(Python · JavaScript · Swift)를 고르면 레슨에서 같은 개념을 그 언어로 쓴 비교 코드를 함께 보여 줍니다. 보지 않음을 골라도 되고, 프로필에서 언제든 바꿀 수 있습니다.

Pick the language you use most (Python, JavaScript, or Swift) and lessons show comparison code in that language. You can also choose none, and change it any time in Profile.

Lisp를 조금 아는데 처음부터 해야 하나요?I know some Lisp. Do I have to start from the beginning?

첫 화면이나 학습 화면의 배치 테스트(10문항)를 보면 됩니다. 단원마다 5문항 중 4문항 이상 맞히면 앞에서부터 그 단원(1·2단원)을 건너뜁니다. 건너뛴 단원은 끝난 것으로 표시되지만 언제든 열어 볼 수 있고, XP는 주지 않습니다. 2단원을 끝내기 전까지는 다시 볼 수 있습니다.

Take the placement test (10 questions) from the first screen or the Learn screen. Answer at least 4 of a unit's 5 questions and that unit (units 1 and 2, in order) is skipped. Skipped units are marked as done but stay open, and give no XP. You can retake it until you finish unit 2.

구매Purchases

무엇이 무료이고 무엇을 사야 하나요?What's free and what do I buy?

1~3단원은 무료입니다. 4단원부터는 트랙 A(4~6단원), 트랙 B(7~9단원), 트랙 C(10~11단원)를 따로 삽니다. 구독이 아니라 한 번 사면 계속 쓰며, 트랙끼리 순서 없이 살 수 있고 산 트랙은 바로 열립니다.

Units 1–3 are free. From unit 4 on, buy Track A (units 4–6), Track B (units 7–9), or Track C (units 10–11). They are one-time purchases, not subscriptions; buy them in any order, and a track opens as soon as you buy it.

새 기기에서 산 트랙이 잠겨 있어요A track I bought is locked on a new device

같은 Apple 계정으로 로그인한 뒤, 잠긴 단원을 눌러 나오는 구매 화면에서 구매 복원을 누르세요.

Sign in with the same Apple Account, tap a locked unit, and choose Restore Purchases on the purchase screen.

환불은 어떻게 하나요?How do I get a refund?

결제는 Apple이 처리하므로 환불도 Apple에 요청합니다: reportaproblem.apple.com

Payments are handled by Apple, so request refunds from Apple: reportaproblem.apple.com

진도와 데이터Progress and data

다른 기기에서도 이어지나요?Does my progress carry over to other devices?

진도와 작성한 코드는 이용자 본인의 iCloud에 저장되어 같은 Apple 계정의 iPhone · iPad · Mac에서 이어집니다. iCloud에 로그인하지 않았거나 설정에서 이 앱의 iCloud를 끄면 그 기기에만 남습니다.

Progress and the code you write are stored in your own iCloud and carry over between your iPhone, iPad, and Mac on the same Apple Account. If you're not signed in to iCloud, or you turn iCloud off for this app in Settings, they stay on that device only.

학습 기록을 내보내거나 지울 수 있나요?Can I export or delete my study data?

프로필의 학습 데이터 내보내기로 JSON 파일을 받을 수 있고, 모든 학습 데이터 삭제로 진도·작성한 코드·읽던 위치를 모든 기기에서 지웁니다(iCloud에서 지워지기까지 몇 분 걸릴 수 있습니다).

In Profile, Export Learning Data gives you a JSON file, and Delete All Learning Data erases your progress, code, and reading positions on all devices (it can take a few minutes to disappear from iCloud).

Lisp 코드 실행Running Lisp code

코드는 어디서 실행되나요?Where does my code run?

앱에 들어 있는 Common Lisp 엔진이 기기 안에서 실행합니다. 인터넷이 없어도 되고, 코드를 밖으로 보내지 않습니다.

A Common Lisp engine built into the app runs it on your device. No internet connection is needed, and your code is never sent anywhere.

SBCL에서 되는 코드가 앱에서 안 돼요Code that works in SBCL doesn't work in the app

앱의 엔진은 ANSI Common Lisp 가운데 학습에 필요한 부분을 구현했습니다. 파일 열기(open, with-open-file), load, compile-file 같은 파일·시스템 기능은 없습니다. 레슨과 문제는 모두 이 엔진과 SBCL에서 같은 결과가 나오는지 확인해 두었습니다. 그 밖에 결과가 다르면 아래로 알려 주세요.

The app's engine implements the parts of ANSI Common Lisp needed for learning. File and system features such as opening files (open, with-open-file), load, and compile-file are not available. Every lesson and problem has been checked to give the same results in this engine and in SBCL. If you find another difference, please let us know below.

코드가 끝나지 않아요My code never finishes

실행 중에 나오는 중단 버튼(키보드 ⌘.)으로 멈출 수 있고, 너무 오래 걸리면 시간 제한으로 멈춥니다. 채점은 테스트 케이스마다 2초 안에 끝나야 합니다. 엔진이 응답하지 않는다는 안내가 나오면 앱을 다시 시작해 주세요. 채점하거나 실행한 코드는 저장되어 있습니다.

Use the Stop button that appears while code runs (⌘. on a keyboard); code that runs too long is stopped by a time limit. When grading, each test case must finish within 2 seconds. If the app says the engine isn't responding, restart the app; the code you graded or ran is saved.

REPL에서 오류가 나면 선택지가 보여요The REPL shows choices after an error

Common Lisp의 재시작(restart)입니다. 코드가 restart-case로 마련해 둔 재시작을 골라 이어 가거나, 최상위로 돌아가(ABORT) 그 실행을 끝낼 수 있습니다. 9단원(컨디션)에서 자세히 배웁니다.

Those are Common Lisp restarts. You can pick a restart that the code set up with restart-case and carry on, or return to the top level (ABORT) to end that run. Unit 9 (Conditions) covers them in detail.
