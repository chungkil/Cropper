이런 앱이에요What it does

Zig 코드를 한 줄씩 실행하며 메모리가 바뀌는 모습을 눈으로 보는 Zig 학습 앱입니다. 함수의 스택 칸, 그 안의 값, 할당자가 빌려준 힙 블록, 포인터와 슬라이스가 가리키는 곳이 그림으로 바뀌고, 방금 바뀐 값은 노랗게 칠해집니다. 앱 화면과 레슨은 한국어로 나옵니다.

A Zig learning app that lets you watch memory change as you run code one line at a time. Stack frames and their values, heap blocks handed out by allocators, and where pointers and slices point are drawn as pictures, and values that just changed are highlighted. The app's screens and lessons are in Korean.

한 줄씩 실행하고 되감기Step forward, step back

  • 다음 줄, 이전 줄, 처음과 끝으로 옮겨 가며 실행합니다
  • 함수 칸이 쌓이고 사라지는 모습, defer가 거꾸로 도는 차례가 보입니다
  • 변수를 누르면 바이트와 비트를 16진수·10진수·2진수·문자로 봅니다
  • comptime으로 바꾸면 컴파일 시간에 계산되는 값을 따로 따라갑니다
  • 가상 마이크로컨트롤러 보드의 LED·버튼·레지스터가 보드 패널에 보입니다
  • Move to the next line, the previous line, the start, or the end
  • Watch frames pile up and disappear, and defer run in reverse order
  • Tap a variable to see its bytes and bits in hex, decimal, binary, or characters
  • Switch to comptime to follow values computed at compile time
  • See the LEDs, buttons, and registers of a virtual microcontroller board

다섯 트랙 · 레슨 113개 · 실습 40개Five tracks, 113 lessons, 40 exercises

  • 트랙 1 Zig 첫걸음 — 첫 프로그램, 값과 자료형, 흐름 제어, 함수와 test 블록 (무료)
  • 트랙 2 Zig 핵심 — 배열과 슬라이스, 포인터, 구조체, 옵셔널, 오류 처리, 문자열, 할당자, 표준 컨테이너
  • 트랙 3 comptime — 컴파일 시간 값과 자료형을 값으로 받는 함수
  • 트랙 4 안전과 메모리 — 검사되는 잘못, 최적화 모드, 비트와 배치
  • 트랙 5 임베디드 Zig — 운영체제 없는 Zig로 가상 보드의 레지스터와 GPIO
  • Track 1 First steps — first program, values and types, control flow, functions and test blocks (free)
  • Track 2 Zig core — arrays and slices, pointers, structs, optionals, errors, strings, allocators, standard containers
  • Track 3 comptime — compile-time values and functions that take types as values
  • Track 4 Safety and memory — checked illegal behavior, optimization modes, bits and layout
  • Track 5 Embedded Zig — freestanding Zig with the registers and GPIO of a virtual board

트랙 1 전체와 트랙 2~5의 첫 모듈은 무료이고, 나머지는 트랙마다 한 번 구매하면 열립니다. 모듈마다 퀴즈와 테스트로 채점되는 실습이 있고, C를 아는 분을 위해 같은 일을 하는 C 코드와 나란히 놓은 대조 카드가 있습니다.

All of Track 1 and the first module of Tracks 2–5 are free; the rest opens with a one-time purchase per track. Every module has a quiz and test-graded exercises, and contrast cards set Zig side by side with C code that does the same thing.

실제 Zig처럼, 기기 안에서Like the real Zig, on the device

이 과정은 Zig 0.17을 가르칩니다. 모든 예제와 실습 답안, 퀴즈 코드를 실제 zig 0.17.1로 돌려 보고 넣었습니다. 컴파일 오류는 한국어 설명과 함께 컴파일러의 원문을 보여 줍니다. 코드는 앱 안의 교육용 Zig 실행기가 기기 안에서 실행하며, 인터넷이 필요하지 않습니다. 광고가 없고 개인정보를 수집하지 않습니다.

The course teaches Zig 0.17. Every example, exercise solution, and quiz program was checked with the real zig 0.17.1. Compile errors come with an explanation and the compiler's original message. Code runs on the device in the app's educational Zig runner, with no internet needed. There are no ads, and no personal information is collected.

지원 기기Requirements

iOS 18 이상의 iPhone과 iPad. iPad와 펼친 접는 iPhone에서는 코드, 메모리, 출력을 한 화면에 나란히 봅니다.

iPhone and iPad with iOS 18 or later. On iPad and an unfolded foldable iPhone, code, memory, and output sit side by side.
