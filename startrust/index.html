Start Rust

C·Java 개발자를 위한 Rust 전환 · iPhone·iPad·MacRust for C and Java developers · iPhone, iPad, Mac

C/C++·Java/Kotlin 경력 개발자가 이미 아는 개념에서 출발해 Rust로 넘어가도록 돕는 학습 앱입니다. 익숙한 코드에서 시작해 Rust 컴파일러가 거절하는 이유를 확인하고, Rust식 해법으로 직접 고쳐 봅니다. A learning app that helps experienced C/C++ and Java/Kotlin developers move to Rust, starting from concepts they already know. Begin with familiar code, see why the Rust compiler rejects it, and fix it the Rust way.

특징Features

기기 안에서 실행·채점 — 코드를 고쳐 바로 실행하고, 실습은 테스트로 채점합니다. 네트워크가 필요 없습니다. Run and grade on device — Edit code and run it right away; exercises are graded with tests. No network needed.

컴파일러 오류 해설 — 실제 rustc 오류를 편집기에 표시하고, 출발 언어에 맞춘 해설 카드를 붙입니다. Compiler error guides — Real rustc errors appear inline in the editor, with explanation cards tailored to the language you come from.

지금은 베타입니다 — TestFlight로 레슨 일부를 먼저 공개하고 있습니다. Currently in beta — A first set of lessons is available through TestFlight.
