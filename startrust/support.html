인터넷이 필요한가요? 아니요. 코드 실행과 채점은 모두 기기 안에서 이루어집니다. Do I need an internet connection? No. Running and grading code happen entirely on your device.

실행이 멈추지 않아요. 실행 중에는 Run 버튼 자리에 중단 버튼이 나옵니다. 실행 시간은 5초로 제한됩니다. My program does not stop. While running, a Stop button replaces Run. Each run is limited to 5 seconds.

앱이 갑자기 종료됐어요. 실행 직전의 코드는 저장되어 있습니다. 다시 열면 안내가 나옵니다. 같은 코드에서 반복되면 이메일로 알려 주세요. The app closed unexpectedly. Your code from just before the run is saved, and the app shows a notice when reopened. If it keeps happening with the same code, please let us know by email.
