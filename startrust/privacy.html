개인정보 처리방침Privacy Policy

앱: Start Rust (iPhone·iPad·Mac) · 최종 수정일: 2026년 11월 25일App: Start Rust (iPhone, iPad, Mac) · Last updated: November 25, 2026

Start Rust의 개발자는 어떤 개인정보도 수집하지 않습니다. The developer of Start Rust does not collect any personal information.

1. 수집하는 정보1. Information We Collect

개발자가 받는 정보는 없습니다. 이 앱에는 로그인, 계정, 광고, 분석 도구, 개발자의 서버가 없으며, 앱은 외부 서버와 통신하지 않습니다. The developer receives no information. The app has no sign-in, no accounts, no ads, no analytics, and no developer servers, and it does not communicate with external servers.

2. 코드 실행2. Running Code

작성한 코드는 기기 안의 Rust 컴파일러와 해석기로만 실행되며 외부로 전송되지 않습니다. 실행되는 코드는 기기의 파일이나 네트워크에 접근할 수 없습니다. Code you write runs only through the Rust compiler and interpreter inside the app on your device and is never transmitted. Running code cannot access your device's files or network.

3. 데이터 저장3. Data Storage

작성한 코드와 설정은 기기 안의 앱 저장 공간에만 저장됩니다. 개발자는 이 데이터에 접근할 수 없으며, 앱을 삭제하면 함께 삭제됩니다. Your code and settings are stored only in the app's storage on your device. The developer cannot access this data, and deleting the app removes it.

4. 제3자 서비스4. Third-Party Services

광고 SDK, 분석 SDK, 소셜 로그인 등 제3자 서비스를 사용하지 않습니다. The app uses no third-party services such as advertising SDKs, analytics SDKs, or social sign-in.

5. 아동의 개인정보5. Children's Privacy

개발자는 어떤 정보도 수집하지 않으므로 아동의 개인정보 역시 수집하지 않습니다. Since the developer collects nothing, no information from children is collected either.

6. 정책 변경6. Changes to This Policy

정책이 변경되면 이 페이지에 게시하고 최종 수정일을 갱신합니다. If this policy changes, we will post the update on this page and revise the date above.
