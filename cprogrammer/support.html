시작하기Getting started

어디서부터 배우면 되나요?Where should I start?

처음 열면 목표를 고르고 짧은 진단 퀴즈를 풀어 시작할 레슨을 추천받습니다. 다시 정하려면 설정 › 시작 지점 다시 정하기를 누르세요. C를 처음 보신다면 트랙 1 "프로그래밍 기초"부터, 다른 언어를 아신다면 트랙 2 "C 언어"부터 권합니다.

On first launch you pick a goal and take a short placement quiz that recommends a starting lesson. To redo it, tap 설정 (Settings) › 시작 지점 다시 정하기 (Choose a new starting point). If C is new to you, start with Track 1 "Programming Basics"; if you already know another language, start with Track 2 "The C Language".

무료로 볼 수 있는 범위는요?What is free?

트랙 1 "프로그래밍 기초" 전체와 트랙 2·3·4의 첫 모듈(2.1 첫 C 프로그램, 3.1 비트·바이트·16진수, 4.1 소스에서 실행까지)은 무료입니다. 나머지 모듈은 트랙마다 한 번 구매하면 열립니다. 잠긴 레슨도 첫 카드는 미리 볼 수 있습니다.

All of Track 1 "Programming Basics" and the first module of Tracks 2, 3, and 4 (2.1 Your First C Program, 3.1 Bits, Bytes, and Hex, 4.1 From Source to Executable) are free. The other modules unlock with a one-time purchase per track. You can preview the first card of a locked lesson.

어떤 기기에서 쓸 수 있나요?Which devices are supported?

iOS 18 이상의 iPhone과 iPadOS 18 이상의 iPad입니다. 인터넷 연결 없이도 모든 기능을 쓸 수 있습니다(트랙 가격 확인과 구매·구매 복원만 App Store에 연결합니다).

iPhone with iOS 18 or later and iPad with iPadOS 18 or later. Every feature works offline; only track prices, purchases, and restoring purchases use the App Store.

구매Purchases

구매한 트랙이 잠겨 보여요.A track I bought still looks locked.

구매할 때와 같은 Apple 계정으로 로그인한 뒤 설정 › 구매 복원을 눌러 주세요. 새 기기나 앱을 다시 설치한 기기에서도 이렇게 열 수 있습니다.

Make sure you are signed in with the same Apple Account you used to buy it, then tap 설정 (Settings) › 구매 복원 (Restore Purchases). This also works on a new device or after reinstalling the app.

환불은 어떻게 하나요?How do I get a refund?

결제는 Apple이 처리하므로 환불도 Apple에 요청합니다: reportaproblem.apple.com

Payments are handled by Apple, so refunds are requested from Apple: reportaproblem.apple.com

진도Progress

진도가 다른 기기로 이어지나요?Does my progress sync to my other devices?

지금은 이어지지 않습니다. 진도·퀴즈·실습 기록은 그 기기 안에만 저장됩니다. 구매한 트랙은 구매 복원으로 어느 기기에서나 열 수 있습니다.

Not yet. Progress, quiz, and exercise records are stored only on each device. Purchased tracks can be unlocked on any device with Restore Purchases.

처음부터 다시 배우고 싶어요.I want to start over.

설정 › 진도 초기화는 레슨 진도, 퀴즈 답, 실습 채점 기록을 모두 지웁니다. 지운 기록은 되돌릴 수 없습니다.

설정 (Settings) › 진도 초기화 (Reset progress) erases all lesson progress, quiz answers, and exercise grades. This cannot be undone.

C 코드 실행Running C code

코드는 어디서 실행되나요?Where does my code run?

앱에 들어 있는 교육용 C 인터프리터가 기기 안에서 실행합니다. 한 줄씩 실행하고 되감으며, 함수를 부를 때 스택에 생기는 칸과 malloc으로 빌린 힙 블록, 포인터가 가리키는 곳을 그림으로 볼 수 있습니다. 프로그램은 앱 안의 가상 메모리에서만 돌아 기기의 파일이나 네트워크에 닿지 않습니다.

An educational C interpreter built into the app runs it on the device. You can step through one line at a time, step back, and watch stack frames, heap blocks from malloc, and where pointers point. Programs run only inside the app's virtual memory and cannot touch the device's files or the network.

실제 컴파일러와 결과가 같나요?Does it behave like a real compiler?

C99와 C11을 지원하고, 실행 결과를 Mac의 clang과 견주어 맞췄습니다. 레슨 예제와 실습 답안, 수백 개의 시험 프로그램이 clang으로 만든 프로그램과 출력·종료 코드까지 같습니다. 오류와 경고도 clang과 같은 문구에 한국어 설명을 붙여 보여 줍니다.

다만 교육용이라 일부 기능은 아직 없습니다: 함수 포인터(qsort 포함), 파일 입출력(fopen), 가변 인자 함수 정의, 넓은 문자 등. 이런 코드를 쓰면 "아직 지원하지 않음"과 그 까닭을 알려 줍니다.

It supports C99 and C11, and its results are checked against clang on the Mac: lesson examples, exercise solutions, and hundreds of test programs produce the same output and exit codes as clang-built programs. Errors and warnings use clang's wording, with an explanation in Korean.

As a teaching tool it does not yet cover everything: function pointers (including qsort), file I/O (fopen), defining variadic functions, wide characters, and a few others. If you use them, the app tells you they are not supported yet and why.

scanf로 입력을 받으려면요?How do I give input to scanf?

코드 편집 화면의 입력 칸에 입력을 미리 적은 뒤 실행하세요. 프로그램은 실행 중에 기다리지 않고 그 입력을 앞에서부터 읽으며, 실행 화면에서 어디까지 읽었는지 진한 글자로 보여 줍니다. 실습은 채점 테스트가 입력을 정합니다.

Type the input in the 입력 (Input) box on the edit screen before running. The program does not pause for input; it reads that text from the start, and the run screen shows in bold how far it has read. In exercises, the grading tests supply the input.

배열 범위를 넘으니 실행이 멈췄어요.My program stopped when I went past the end of an array.

실제 C라면 조용히 옆 메모리를 망가뜨리는 실수(배열 범위 넘기, 해제한 메모리 쓰기, 이중 해제, 초기화 전 읽기 등)를 앱이 그 자리에서 멈추거나 경고하고 무슨 일이 일어났는지 설명합니다. 일부 레슨은 실제 기기처럼 덮어쓰는 모습을 일부러 보여 줍니다.

Mistakes that silently corrupt memory in real C (going past an array, using freed memory, freeing twice, reading before initializing, and so on) are stopped or flagged on the spot with an explanation. A few lessons deliberately show the overwrite as it would happen on a real machine.
