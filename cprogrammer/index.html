한 줄씩 실행하고 되감기Step forward, step back

다음 줄·이전 줄·중단점까지 옮겨 가며 함수를 부를 때 생기는 스택 프레임, malloc으로 빌린 힙 블록, 포인터가 가리키는 곳을 그림으로 봅니다. 방금 바뀐 값은 노랗게 칠해집니다.

Move to the next line, the previous line, or a breakpoint, and watch stack frames appear on each call, heap blocks from malloc, and arrows to where pointers point. Values that just changed are highlighted.

레슨 99개 · 퀴즈 · 실습 44개99 lessons, quizzes, 44 exercises

짧은 카드로 된 레슨에서 예제를 바로 실행하고, 모듈마다 퀴즈(메모리 그림 맞추기, 빈칸 채우기 포함)와 자동 채점되는 실습 두 개로 확인합니다.

Bite-sized lesson cards with runnable examples, a quiz for every module (including memory-picture matching and fill-in-the-blank), and two auto-graded exercises per module with hints.

오류를 한국어로Errors explained in Korean

clang과 같은 오류·경고에 한국어 설명과 관련 레슨을 붙여 보여 줍니다. 배열 범위 넘기, 해제한 메모리 쓰기 같은 메모리 버그는 그 자리에서 알려 줍니다.

Errors and warnings match clang's, with a Korean explanation and a link to the related lesson. Memory bugs such as writing past an array or using freed memory are caught where they happen.

C99 · C11, 기기 안에서C99 and C11, on the device

앱에 들어 있는 교육용 C 인터프리터가 실행하고, 결과는 Mac의 clang과 견주어 맞췄습니다. 작성한 코드는 기기를 떠나지 않습니다.

An educational C interpreter inside the app runs your code, with results checked against clang on the Mac. Your code never leaves the device.
