개인정보 처리방침Privacy Policy

C 프로그래머 과정 · 최종 수정 2026년 10월 7일 C Programmer Course · Last updated October 7, 2026

개발자는 이용자의 개인정보를 수집하지 않습니다. 학습 기록과 작성한 코드는 이용자의 기기 안에만 있고, 광고와 분석 도구도 없습니다. The developer collects no personal information. Your study records and the code you write stay on your device, and the app contains no ads and no analytics.

1. 수집하는 정보1. Information we collect

개발자가 수집하는 정보는 없습니다. 회원 가입과 로그인이 없고, 개발자가 운영하는 서버도 없습니다. 이름·이메일·전화번호·연락처·위치 같은 정보를 수집하거나 전송하지 않습니다.

The developer collects nothing. There is no sign-up, no login, and no developer-operated server. We do not collect or transmit names, email addresses, phone numbers, contacts, or location.

2. 학습 기록이 저장되는 곳2. Where your study data lives

레슨 진도(어디까지 봤는지, 마친 레슨), 퀴즈 답과 점수, 실습에서 채점한 코드, 설정(기본 C 표준, 추천받은 시작 레슨)은 이 기기 안에만 저장됩니다. 앱이 iCloud나 다른 곳으로 보내지 않으므로 다른 기기와 이어지지 않습니다. (이용자가 켜 둔 기기 전체 백업에는 다른 앱의 데이터처럼 함께 들어갈 수 있습니다.)

Lesson progress (where you stopped and which lessons you finished), quiz answers and scores, the code you graded in exercises, and settings (default C standard, recommended starting lesson) are stored only on this device. The app sends nothing to iCloud or anywhere else, so records do not carry over to your other devices. (A whole-device backup you have turned on may include them, like any other app's data.)

앱의 설정 › 진도 초기화로 학습 기록을 지울 수 있고, 앱을 지우면 기록도 함께 지워집니다.

You can erase your study records in 설정 (Settings) › 진도 초기화 (Reset progress), and deleting the app removes them as well. The app's screens are in Korean.

3. 작성한 C 코드3. The C code you write

작성한 C 프로그램은 앱에 들어 있는 교육용 C 인터프리터가 기기 안에서 실행합니다. 코드를 외부로 보내지 않고, 실행에 인터넷 연결이 필요하지 않습니다. 프로그램은 앱 안의 가상 메모리에서만 돌며 기기의 파일·네트워크·다른 앱에 닿지 않습니다.

연습장에 쓴 코드는 저장하지 않습니다(열 때마다 예제 코드로 새로 시작합니다). 실습은 채점한 코드만 위 2번처럼 기기에 남깁니다.

Your C programs run on the device in the educational C interpreter built into the app. Code is never sent anywhere, and running it needs no internet connection. Programs run only inside the app's virtual memory and cannot reach the device's files, the network, or other apps.

Code written in the playground is not saved (it starts from the sample code each time). For exercises, only the code you grade is kept on the device, as described in section 2.

4. 인앱 구매4. In-app purchases

트랙 구매는 Apple의 App Store를 통해서만 이루어집니다. 결제 정보는 Apple이 처리하며 개발자에게 전달되지 않습니다. 앱은 어느 트랙을 구매했는지만 확인합니다.

Track purchases are processed entirely by Apple's App Store. Payment details are handled by Apple and never reach the developer. The app only checks which tracks you own.

5. 광고 · 분석 · 추적5. Ads, analytics, and tracking

광고가 없고 분석 도구도 넣지 않았습니다. 이용 통계를 개발자에게 보내지 않으며, 다른 회사의 앱이나 웹사이트에 걸쳐 이용자를 추적하지 않으므로 추적 동의 요청도 표시하지 않습니다.

No ads and no analytics. The app sends no usage statistics to the developer and does not track you across other companies' apps or websites, so it never shows a tracking permission prompt.

6. 아동의 개인정보6. Children's privacy

이 앱은 어린이를 포함한 모든 연령이 쓸 수 있으며, 개발자는 연령과 상관없이 어떤 개인정보도 수집하지 않습니다.

The app is suitable for all ages, including children, and the developer collects no personal information from anyone.
