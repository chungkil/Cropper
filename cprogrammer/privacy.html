개인정보 처리방침Privacy Policy

스타트 C 프로그래밍 · 최종 수정 2026년 10월 28일 Start C Programming · Last updated October 28, 2026

개발자는 이름·이메일 같은 개인정보를 수집하지 않습니다. 학습 기록과 작성한 코드는 이용자의 기기 안에만 있고, 광고가 없습니다. 앱을 고치는 데 쓰려고 Google 애널리틱스로 익명의 이용 통계(트랙 진행률, 트랙 구매 등)만 받습니다. The developer collects no personal information such as your name or email. Your study records and the code you write stay on your device, and the app contains no ads. To improve the app, it sends only anonymous usage statistics (such as track progress and track purchases) to Google Analytics.

1. 수집하는 정보1. Information we collect

개발자가 직접 수집하는 개인정보는 없습니다. 회원 가입과 로그인이 없고, 개발자가 운영하는 서버도 없습니다. 이름·이메일·전화번호·연락처·정확한 위치 같은 정보를 수집하거나 전송하지 않습니다. 익명의 이용 통계는 5번에 적은 대로 Google 애널리틱스로 보냅니다.

The developer does not directly collect personal information. There is no sign-up, no login, and no developer-operated server. We do not collect or transmit names, email addresses, phone numbers, contacts, or precise location. Anonymous usage statistics go to Google Analytics as described in section 5.

2. 학습 기록이 저장되는 곳2. Where your study data lives

레슨 진도(어디까지 봤는지, 마친 레슨), 퀴즈 답과 점수, 실습에서 채점한 코드, 설정(기본 C 표준, 추천받은 시작 레슨)은 이 기기 안에만 저장됩니다. 이 기록을 iCloud나 다른 곳으로 보내지 않으므로 다른 기기와 이어지지 않습니다 (레슨을 마칠 때 그 트랙의 진행률만 5번의 이용 통계로 보냅니다). (이용자가 켜 둔 기기 전체 백업에는 다른 앱의 데이터처럼 함께 들어갈 수 있습니다.)

Lesson progress (where you stopped and which lessons you finished), quiz answers and scores, the code you graded in exercises, and settings (default C standard, recommended starting lesson) are stored only on this device. These records are not sent to iCloud or anywhere else, so they do not carry over to your other devices (when you finish a lesson, only that track's progress is sent as a usage statistic, see section 5). (A whole-device backup you have turned on may include them, like any other app's data.)

앱의 설정 › 진도 초기화로 학습 기록을 지울 수 있고, 앱을 지우면 기록도 함께 지워집니다.

You can erase your study records in Settings › Reset progress, and deleting the app removes them as well.

3. 작성한 C 코드3. The C code you write

작성한 C 프로그램은 앱에 들어 있는 교육용 C 인터프리터가 기기 안에서 실행합니다. 코드를 외부로 보내지 않고, 실행에 인터넷 연결이 필요하지 않습니다. 프로그램은 앱 안의 가상 메모리에서만 돌며 기기의 파일·네트워크·다른 앱에 닿지 않습니다.

프로그램이 읽고 쓰는 파일은 앱 안의 가상 파일이라 기기의 파일에 닿지 않고, 실행이 끝나면 저장하지 않습니다.

프로세스·스레드·파이프·소켓도 앱 안에서 가상으로 만들어지며, 소켓은 앱 안의 루프백에서만 연결되어 기기 밖으로 아무것도 보내지 않습니다.

연습장에 쓴 코드는 저장하지 않습니다(열 때마다 예제 코드로 새로 시작합니다). 실습은 채점한 코드만 위 2번처럼 기기에 남깁니다.

Your C programs run on the device in the educational C interpreter built into the app. Code is never sent anywhere, and running it needs no internet connection. Programs run only inside the app's virtual memory and cannot reach the device's files, the network, or other apps.

Files your program reads and writes are virtual files inside the app; they never touch the device's files and are not saved after the run.

Processes, threads, pipes, and sockets are also created virtually inside the app, and sockets connect only over loopback inside the app, so nothing is sent off the device.

Code written in the playground is not saved (it starts from the sample code each time). For exercises, only the code you grade is kept on the device, as described in section 2.

4. 인앱 구매4. In-app purchases

트랙 구매는 Apple의 App Store를 통해서만 이루어집니다. 결제 정보는 Apple이 처리하며 개발자에게 전달되지 않습니다. 앱은 어느 트랙을 구매했는지만 확인하고, 구매한 트랙과 상품 ID·가격을 5번의 이용 통계로 보냅니다.

Track purchases are processed entirely by Apple's App Store. Payment details are handled by Apple and never reach the developer. The app only checks which tracks you own, and sends the purchased track, product ID, and price as a usage statistic (section 5).

5. 광고 · 분석 · 추적5. Ads, analytics, and tracking

광고는 없습니다. 앱을 고치는 데 쓰려고 Google 애널리틱스(Firebase)로 익명의 이용 통계를 받습니다: 앱 실행과 사용 시간, 레슨을 마칠 때의 트랙 진행률(트랙·레슨 번호, 마친 레슨 수), 트랙 구매(상품 ID, App Store가 알려 주는 가격), 기기 종류와 OS 버전, IP 주소로 짐작한 대략의 지역입니다. 이 통계는 앱을 설치할 때마다 새로 만들어지는 무작위 식별자에만 묶이며, 이름·이메일 같은 개인정보나 작성한 코드·퀴즈 답은 보내지 않습니다.

광고 식별자(IDFA)를 쓰지 않고, 다른 회사의 앱이나 웹사이트에 걸쳐 이용자를 추적하지 않으므로 추적 동의 요청도 표시하지 않습니다. 보낸 통계는 Google의 개인정보처리방침(policies.google.com/privacy)에 따라 처리됩니다.

No ads. To improve the app, it sends anonymous usage statistics to Google Analytics (Firebase): app launches and time in the app, track progress when you finish a lesson (track and lesson numbers, lessons finished), track purchases (product ID and the price reported by the App Store), device model and OS version, and an approximate region inferred from your IP address. These statistics are tied only to a random identifier created for each installation of the app; no personal information such as your name or email, and none of your code or quiz answers, is sent.

The app does not use the advertising identifier (IDFA) and does not track you across other companies' apps or websites, so it never shows a tracking permission prompt. The statistics are handled under Google's Privacy Policy (policies.google.com/privacy).

6. 아동의 개인정보6. Children's privacy

이 앱은 어린이를 포함한 모든 연령이 쓸 수 있으며, 개발자는 연령과 상관없이 이름·이메일 같은 개인정보를 수집하지 않습니다. 5번의 익명 이용 통계는 모든 이용자에게 같습니다.

The app is suitable for all ages, including children, and the developer collects no personal information such as names or email addresses from anyone. The anonymous usage statistics in section 5 are the same for every user.
